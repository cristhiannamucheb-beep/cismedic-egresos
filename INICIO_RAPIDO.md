# 🚀 INICIO RÁPIDO - Sistema de Control de Egresos

## ⚡ 3 Pasos para Empezar

### 1️⃣ Iniciar XAMPP
```
Abre XAMPP Control Panel
Haz clic en START para:
  ✓ Apache
  ✓ MySQL
```

### 2️⃣ Acceder al Sistema
```
Abre tu navegador y ve a:
http://localhost/CISMEDIC_EGRESOS/
```

### 3️⃣ Iniciar Sesión
```
Usa las credenciales asignadas por el administrador de la instalación.
No publiques contraseñas en documentación ni en GitHub.
```

## ❓ ¿Problemas?

**Si la página no carga:**
- Verifica que Apache y MySQL estén corriendo en XAMPP
- Asegúrate de que la BD `clinica` exista

**Si hay error de conexión:**
- Crea `config/database.local.php` con las credenciales locales de MySQL. Usa el formato del README.
- No escribas contraseñas reales en `config/database.php` ni las subas a GitHub.

**Más ayuda:**
- Lee el archivo README.md completo
- Revisa los logs de XAMPP
